# Roadmap

## Phase 0 — Scaffold (now)
- Repo structure + docs
- Minimal webhook receiver
- Signature verification
- Log and store incoming email payloads

## Phase 1 — Prioritization
- Rules engine (VIP senders, keywords, waitlist signals)
- Basic scoring
- Priority notifications to Beeper

## Phase 2 — Actions
- Unsubscribe workflow (List‑Unsubscribe header parsing)
- Blocklist/allowlist management
- Safety flags for social engineering / phishing / NSFW

## Phase 3 — Voice
- ElevenLabs agent for spoken alerts
- Daily spoken briefing

## Phase 4 — Multi‑provider
- Gmail/iCloud fetch for legacy mail
- Forwarded domains + Cloudflare routing
