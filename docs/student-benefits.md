# Student/Free Resources (Live links)

This list favors sources that explicitly state credits/benefits. Offers change—verify on the page before applying.

## GitHub Student Developer Pack
- https://education.github.com/pack
- The pack aggregates student‑verified offers. You must log in with a verified student account to see current details.

## ElevenLabs Grants (not student‑specific, but high value)
- Grants application: https://elevenlabs.io/grants-application
  - States: **33,000,000 free credits** over **12 months** for approved grants.
- Startup grants: https://elevenlabs.io/startup-grants
  - States: **12 months free**, **33,000,000 characters**, “680+ hours” equivalent.
